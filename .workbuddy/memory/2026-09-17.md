# 2026-09-17

## debug_tools: 更新依赖并切换 Android SDK 到 android-36.1

- 本机 SDK 只剩 `platforms;android-36.1`（Android 16 QPR2）、build-tools 36.1.0、NDK 30.0.16248370；NDK 28.2.13676358 目录损坏（缺 source.properties）。
- `android/app/build.gradle.kts`：`compileSdk = flutter.compileSdkVersion` 改为 `compileSdk { version = release(36) { minorApiLevel = 1 } }`（36.1 必须用 minor DSL；AGP 9.1.0 支持，最低要求 8.13.0），并显式 `ndkVersion = "30.0.16248370"`、`buildToolsVersion = "36.1.0"`。
- `android/build.gradle.kts`：新增对全部 `com.android.library` 子项目（插件）的统一覆盖，钩子用 `androidComponents.finalizeDsl`（AGP 官方"DSL 锁定前最后修改"入口）。踩过的时机坑：
  1. `plugins.withId` 直接改 → 被插件自己的赋值覆盖回去（回调在插件脚本体执行前触发）；
  2. `afterEvaluate` 改 → "It is too late to set compileSdk"（DSL 已锁定）；
  3. `finalizeDsl` 才是正确时机：晚于插件脚本体、早于锁定。
- 通配符泛型 `AndroidComponentsExtension<*, *, *>` 在 Kotlin DSL 中无法解析成员，必须用具体类型 `LibraryAndroidComponentsExtension`（library 模块）。
- Flutter 引擎工件（io.flutter:*_release）默认走 `storage.googleapis.com/download.flutter.io`（可用环境变量 `FLUTTER_STORAGE_BASE_URL` 覆盖，或在 allprojects.repositories 最前面加 `https://storage.flutter-io.cn/download.flutter.io` 镜像优先命中），国内直连会被 Connection reset。
- `flutter pub upgrade` 因 `environment: sdk: ^3.13.0` 等约束无法升级 minor 版本（38 个包有更新但受约束），保持现状。
- 最终 `flutter build apk --release` 成功：`build/app/outputs/flutter-apk/app-release.apk`（55.0MB）。
- Flutter 版本 3.47.4 stable；KGP 警告：mobile_scanner 仍用旧 Kotlin 插件，未来 Flutter 版本会失败，留意其升级。

# 调试工具协议说明（Modbus 篇）

本文档为随应用发布的演示示例。使用 Modbus 调试工具时，请结合目标
设备或服务的实际协议，自行维护指令模板与协议说明（个人完整版可通过
`--dart-define=APP_PROFILE=full` 构建时启用完整文档）。

## 通道基础

Modbus TCP 是主站轮询协议，不主动向服务器“提交”数据。主站通过功能码
`01/02/03/04` 读取运行数据，通过 `05/06/0F/10` 下发控制。

- 从站端口：TCP `502`；
- MBAP Unit Identifier 不限定，响应原样回显请求值；
- 寄存器地址均为协议 PDU 中的**零基地址**；某些软件界面显示为 `00001`、
  `30001`、`40001` 等一基编号，使用时需按软件规则换算；
- 多字数据统一使用**高字在前**：地址较小的寄存器是 `uint32` 的高 16 位。

## 线圈（功能码 01/05/0F）

| 零基地址 | 内容 | 访问 |
|---:|---|---|
| `0x0000` | DO0 实际状态/手动控制 | 读写 |
| `0x0001` | DO1 实际状态/手动控制 | 读写 |

写单线圈只接受标准值 `0xFF00`（ON）和 `0x0000`（OFF）。

## 离散输入（功能码 02）

| 零基地址 | 内容 |
|---:|---|
| `0x0000`–`0x0001` | DO0–DO1 实际状态 |
| `0x0002`–`0x0003` | 联动规则启用状态 |
| `0x0004`–`0x0005` | 联动表达式当前计算结果 |
| `0x0006`–`0x0007` | 联动规则有效状态 |

## 输入寄存器（功能码 04，只读）

| 零基地址 | 内容 |
|---:|---|
| `0x0000` | 映射版本 |
| `0x0001` | 计数通道数量 |
| `0x0002` | 输出数量 |
| `0x0010`–`0x0011` | counter0，uint32 高字/低字 |
| `0x0012`–`0x0013` | counter1，uint32 高字/低字 |
| `0x0014`–`0x0015` | counter2，uint32 高字/低字 |
| `0x0016`–`0x0017` | counter3，uint32 高字/低字 |
| `0x0020` | 输出位图，bit0=DO0、bit1=DO1 |
| `0x0021` | 联动启用位图，bit0=OUT0、bit1=OUT1 |
| `0x0022` | 联动有效位图 |
| `0x0023` | 联动表达式结果位图 |
| `0x0024` | 联动 true 电平位图 |
| `0x0030`–`0x0031` | 设备运行秒数，uint32 高字/低字 |

## 保持寄存器（功能码 03/06/10）

| 零基地址 | 内容 | 访问及约束 |
|---:|---|---|
| `0x0000` | 命令寄存器 | 读为 0；仅用 FC06 写入 |
| `0x0010`–`0x0011` | counter0 | 读；FC10 必须从高字起一次写 2 个寄存器 |
| `0x0012`–`0x0013` | counter1 | 同上 |
| `0x0014`–`0x0015` | counter2 | 同上 |
| `0x0016`–`0x0017` | counter3 | 同上 |
| `0x0020` | 输出位图 | 读；FC06 写，值只允许 `0`–`3` |

命令寄存器写入后立即执行，不保存命令值：

| 写入值 | 操作 |
|---:|---|
| `0x0001`–`0x0004` | 分别复位 counter0–counter3 |
| `0x0010` | 复位全部计数器 |
| `0x0021`–`0x0024` | 分别将 counter0–counter3 加一 |

## 异常响应

- `01`：不支持的功能码。
- `02`：地址或地址范围不在映射内。
- `03`：数量、长度、线圈值、命令值或寄存器值非法。
- `04`：设备控制层执行失败。
